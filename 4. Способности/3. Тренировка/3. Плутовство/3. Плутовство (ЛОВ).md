# Повышение пассивной сложности спасбросков против эффектов (Плутовства):

1. Плутовство +2 = Пассивная сложность спасброска против эффектов (Плутовства): +4.
2. Плутовство +3 = Пассивная сложность спасброска против эффектов (Плутовства) еще +6 (Всего: +10).
3. Плутовство +5 = Пассивная сложность спасброска против эффектов (Плутовства) еще +8 (Всего: +12).

Эти способности можно брать в любом порядке.
