(А) Стандартное действие (1р/Раунд) (Выносливость: 20)
Требования: ТЕЛ / ЛОВ: 3 или ИНТ / ХАР / ВОС / ОБА / УДЧ: 3 и Дальний бой (ИНТ / ХАР / ВОС / ОБА / УДЧ).
Дополнительное требование: ваш персонаж должен быть вооружен оружием дальнего боя (Лук).

1. Ваш персонаж атакует цель в (Дальнем бою).
2. В случае попадания, цель получает урон по здоровью (Оружие дальнего боя).
3. После получения урона, цель должна пройти спасбросок против пассивной сложности навыка:
4. Дальний бой - эффект - (Ослабление) - (Физический) - (ФИЗ). 
5. В случае провала на цель накладывается состояние (Замедление).
# Замедление

1. Скорость цели снижается на 6 клеток.
2. Если скорость опускается до 0, цель не может передвигаться.
3. Цель не может использовать способности позволяющие ей передвигаться.
4. Эффект действует до конца сцены. 
# Избавление от эффекта

1. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка:
2. Дальний бой - эффект - (Уязвимость) - (Физический) - (ФИЗ). 

Свойства способности:
1. Эффект: Нанесение урона / Ослабление.
2. Источник: Физический / Физический.
3. Тип: ФИЗ / ФИЗ.
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: Дальний бой вашего персонажа / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца сцены.
