(А) Малое действие (1р/Раунд) (Выносливость: 20)
Требования: ИНТ / ВОС / ОБА / УДЧ: 3 и Ближний бой (ИНТ / ВОС / ОБА / УДЧ).

1. Ваш персонаж атакует цель в (Дальнем бою).
2. В случае попадания, цель получает урон по рассудку (Оружие дальнего боя + 2d8).
3. Параметры урона меняются на (Внутренний - Психика - МЕНТ).
4. После получения урона, цель должна пройти спасбросок пройти спасбросок против пассивной сложности навыка:
5. Дальний бой - эффект - (Отвлечение) - (Психика) - (МЕНТ). 
6. В случае провала на цель накладывается состояние (Провокация).
7. У вашего персонажа есть 2 вариант использования этого эффекта.
8. Он может наложить его по отношению к себе (как обычно) или по отношению к любому другому персонажу в радиусе 10 клеток вокруг себя. 
9. Выбранный в качестве объекта провокации персонаж не получает никаких спасбросков против этого эффекта. 
# Провокация

1. Цель может атаковать и предпринимать агрессивные действия только по отношению к персонажу, которые ее спровоцировал. 
2. Эффект действует до конца следующего хода цели. 
# Избавление от эффекта

1. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка:
2. Дальний бой - эффект - (Отвлечение) - (Физический) - (ФИЗ).

Свойства способности:
1. Эффект: Нанесение урона / Отвлечение.
2. Источник: Психика / Психика.
3. Тип: МЕНТ / МЕНТ.
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: Дальний бой вашего персонажа / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца следующего хода цели.
