Специализация дальнего боя позволяющая вашему персонажу эффективно использовать оружие предназначенное для создания колоссальных разрушений: пулеметы и артиллерия.  Помимо этого, она позволяет персонажу хорошо переносить получаемый урон и потрясения.

Итоговое усиление параметров вашего персонажа после прокачки:

# Критические атаки

1. Диапазон критического попадания для атак оружием дальнего боя (Пулеметы): +2.
2. Критический урон для атак оружием дальнего боя (Пулеметы): +20. 
3. Диапазон критического попадания для атак оружием дальнего боя (Артиллерия): +2.
4. Критический урон для атак оружием дальнего боя (Артиллерия): +20.
