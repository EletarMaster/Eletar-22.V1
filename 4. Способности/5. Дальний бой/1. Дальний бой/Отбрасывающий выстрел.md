(А) Малое действие (1р/Раунд) (Выносливость: 20)
Требования: ТЕЛ / ЛОВ: 2.

1. Ваш персонаж атакует все цели в конусе длинною 3 клетки в (Дальнем бою).
2. В случае попадания, все цели получают урон по здоровью (Оружие дальнего боя).
3. После получения урона, цели должны пройти спасбросок против пассивной сложности навыка:
4. Дальний бой - эффект - (Вынужденное движение) - (Физический) - (ФИЗ). 
5. В случае провала цели отбрасываются на 5 клеток назад. 
6. Эта атака является массовой.
7. Эту атаку нельзя контратаковать.


Свойства способности:
1. Эффект: Нанесение урона / Вынужденное движение.
2. Источник: Физический / Физический.
3. Тип: ФИЗ / ФИЗ. 
4. Цель: Все противники в шаблоне / Цель первоначального воздействия.
5. Шаблон: Конус длинною 3 клетки / Цель первоначального воздействия.
6. Дистанция: 3 клетки / Цель первоначального воздействия.
7. Длительность: Мгновенно / Мгновенно.
