Ветка позволяющая многогранно усилить вашего персонажа, заимствовать сильные стороны других веток. Улучшает его бдительность и позволяет действовать на пределе своих возможностей. 

Итоговое усиление параметров вашего персонажа после прокачки:
# Спасброски

1. Ваш персонаж может использовать (ВОС) в качестве характеристики для спасбросков против эффектов с типом (ФИЗ).
2. Ваш персонаж может использовать (ВОС) в качестве характеристики для спасбросков против эффектов с типом (МЕНТ).
3. Ваш персонаж может использовать (ВОС) в качестве характеристики для спасбросков против эффектов с типом (МИСТ).
4. Спасбросок против эффектов с типом (ФИЗ): +2.
5. Спасбросок против эффектов с типом (МЕНТ): +2.
6. Спасбросок против эффектов с типом (МИСТ): +2.
# Навыки

1. Ваш персонаж может полноценно использовать (ВОС) как характеристику для (Акробатики).
2. Ваш персонаж может полноценно использовать (ВОС) как характеристику для (Плутовства).
# Защиты

1. Защита (Уклонение): +4.
2. Защита (Пассивная внимательность): +4.
3. Ваш персонаж может использовать (ВОС) в качестве характеристики для использования защиты (Уклонение).
