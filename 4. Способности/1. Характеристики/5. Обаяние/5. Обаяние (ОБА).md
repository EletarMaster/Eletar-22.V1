Ветка повышающая привлекательность персонажа, позволяющая расположить окружающих к себе и воздействовать на них путем социальных взаимодействий. 

Итоговое усиление параметров персонажа после прокачки:

# Спасброски

1. Персонаж может использовать (ОБА) в качестве характеристики для спасбросков против эффектов с типом (МЕНТ).
2. Персонаж может использовать (ОБА) в качестве характеристики для спасбросков против эффектов с типом (МИСТ).
3. Спасбросок против эффекта (Похищение): +4.
4. Превосходство на все спасброски против эффекта (Похищение).
# Навыки

1. Персонаж может полноценно использовать (ОБА) как характеристику для (Внимательности).
2. Персонаж может полноценно использовать (ОБА) как характеристику для (Плутовства).
# Защиты

1. Персонаж может использовать (ОБА) в качестве характеристики для использования защиты (Пассивная внимательность).
# Сложность спасброска против эффектов персонажа

1. Пассивная сложность спасброска против эффектов с типом (МЕНТ), накладываемых персонажем: +10.
# Минимальный результат проверки

1. Минимальный результат броска d20 при проверках обаяния персонажа = 10.
