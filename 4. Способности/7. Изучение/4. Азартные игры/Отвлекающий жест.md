(А) Малое действие (1р/Раунд) (Рассудок: 10)
Требования: ЛОВ / ИНТ / ОБА / ВОС / УДЧ: 2.

1. Ваш персонаж совершает встречную проверку с целью:
2. (Азартные игры) вашего персонажа против спасброска цели (Отвлечение) - (Психика) - (МЕНТ). 
3. В случае, если результат вашего персонажа превышает результат цели, на нее накладывается состояние (Сбитое внимание).
4. Не считается агрессивным действием. 
# Сбитое внимание

1. Цель получает помехи на все броски внимательности. 
2. Она предоставляет превосходство для всех атак по себе.
3. Эффект действует до конца сцены.
# Избавление от эффекта

1. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка:
2. Азартные игры - эффект - (Отвлечение) - (Психика) - (МЕНТ). 

Свойства способности:
1. Эффект: Отвлечение.
2. Источник: Психика.
3. Тип: МЕНТ. 
4. Цель: 1 Цель.
5. Шаблон: 1 Цель.
6. Дистанция: 10 клеток.
7. Длительность: Мгновенно.
