Требования: ТЕЛ / ЛОВ: 3 или ИНТ / ХАР / ВОС / ОБА / УДЧ: 3 и Ближний бой (ИНТ / ХАР / ВОС / ОБА / УДЧ).

1. Ступень костей урона оружия ближнего боя (Прикалады): +1.
2. Количество костей урона оружия ближнего боя (Приклады): +1.
3. Диапазон критического попадания для атак оружия ближнего боя (Приклады): +1.
4. Критический урон для атак оружия ближнего боя (Приклады): +10.
