(Р) Реакция (1р/Раунд) (Выносливость: 40)
Требования: ТЕЛ / ЛОВ: 4 или ХАР / ВОС: 4 и Ближний бой (ХАР / ВОС).
Условия срабатывания: по вашему персонажу попали атакой ближнего боя о которой он знает.
Дополнительное требование: ваш персонаж должен использовать только (Рукопашный бой). 

1. Ваш персонаж избегает попавшую по нему атаку, полностью игнорируя ее.
2. Сразу же после этого, ваш персонаж может нанести атаку (Ближнего боя) по любой цели на дальности своего ближнего боя. 
3. Ваш персонаж получает превосходство на бросок этой атаки.
4. В случае попадания, цель получает урон по здоровью (Рукопашный бой) персонажа. 
5. Является контратакой. 

Свойства способности:
1. Эффект: Снижение урона / Нанесение урона.
2. Источник: Физический / Физический.
3. Тип: ФИЗ / ФИЗ. 
4. Цель: Ваш персонаж / 1 Цель.
5. Шаблон: Ваш персонаж / 1 Цель.
6. Дистанция: Ваш персонаж / 1 Цель.
7. Длительность: Мгновенно / Мгновенно.
