(П) Пассивная способность
Требования: ТЕЛ / ЛОВ: 3 или ИНТ / ХАР / ВОС: 3 и Ближний бой (ИНТ / ХАР / ВОС).

1. Диапазон критического попадания для атак оружием ближнего боя (Щиты): +1.
2. Каждый раз, когда ваш персонаж наносит критический удар используя щит, после получения урона, цель должна пройти спасбросок против пассивной сложности навыка:
3. Ближний бой - эффект - (Блокировка) - (Физический) - (ФИЗ). 
4. В случае провала на цель накладывается состояние (Оглушение).
# Оглушение

1. Цель не может предпринимать никаких действий или передвигаться.
2. Она предоставляет превосходство для всех атак по себе
# Избавление от эффекта

1. Эффект действует до конца следующего хода цели. 
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка:
3. Ближний бой - эффект - (Блокировка) - (Физический) - (ФИЗ).
