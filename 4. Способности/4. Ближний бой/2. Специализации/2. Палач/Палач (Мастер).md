(П) Пассивная способность
Требования: ТЕЛ / ЛОВ / ВОС: 3 и Ближний бой (Ученик)

1. Прием (Свободная атака) для вашего персонажа (Свободное действие), а не (Действие - реакция).
2. Помимо этого, он может использовать этот прием сколько угодно раз в раунд, а не один раз в раунд. 
3. Ваш персонаж может полноценно использовать (ВОС) как характеристику для (Атака бб).
4. Ваш персонаж может использовать (ВОС) как характеристику для защиты (Ближний бой).
5. (ВОС) все еще не заменяет характеристики, необходимую вашему персонажу для получения доступа к специализациям (Ближнего боя).
