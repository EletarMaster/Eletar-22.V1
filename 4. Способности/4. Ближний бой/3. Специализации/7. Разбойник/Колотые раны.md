(П) Пассивная способность
Требования: ЛОВ: 3 или ИНТ / ВОС / ОБА / УДЧ: 3 и Ближний бой (ИНТ / ВОС / ОБА / УДЧ).

1. Если у вашего персонажа есть превосходство над целью, он не испытывает штрафов за прицельные атаки ближнего боя по ней.
2. Диапазон критического попадания для атак (Ближнего боя): +1. 
3. Критический урон для атак (Ближний бой): +10.
