(А) Стандартное действие (1р/Сцена) (Рассудок: 20).
Требования: ТЕЛ / ЛОВ / ИНТ / ХАР / ОБА / ВОС / УДЧ: 3.
Подходящее выступление: Пение / Танцы / Исполнение / Актерство.

1. Ваш персонаж совершает встречную проверку с всеми целями в радиусе 5 клеток вокруг него:
2. ([[Пение]] / [[Танцы]] / [[Исполнение]] / [[Актерство]]) вашего персонажа против спасброска целей ([[Отвлечение]]) - ([[Звук]]) - ([[МЕНТ]]). 
3. В случае, если результат вашего персонажа превышает результат целей, на них накладывается состояние ([[(-) Сбитое внимание]]).
4. Является громким действием привлекающим к себе внимание. 
5. Не считается агрессивным действием. 
# (+) Сбитое внимание

1. Цель получает помехи на все броски навыка ([[Внимательность]]).
2. Она предоставляет превосходство для всех атак по себе.
# Избавление от эффекта

1. Эффект действует до конца сцены.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Пение]] / [[Танцы]] / [[Исполнение]] / [[Актерство]]) - эффект - ([[Отвлечение]]) - ([[Звук]]) - ([[МЕНТ]]). 

Свойства способности:
1. Эффект: Отвлечение.
2. Источник: Звук.
3. Тип: МЕНТ. 
4. Цель: Все противники в шаблоне.
5. Шаблон: 5 клеток вокруг вашего персонажа.
6. Дистанция: 5 клеток.
7. Длительность: До конца сцены.
