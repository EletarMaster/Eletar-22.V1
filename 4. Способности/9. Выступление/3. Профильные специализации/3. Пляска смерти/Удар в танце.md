(А) Стандартное действие (1р/Раунд) (Выносливость: 20).
Требования: ТЕЛ / ЛОВ / ХАР / ОБА / УДЧ: 3.
Подходящее выступление: Танцы.
Дополнительное требование: ваш персонаж должен находится под состоянием (Танец).

1. Ваш персонаж атакует цель в ([[Ближнем бою]]).
2. В случае попадания, цель получает урон по здоровью ([[Оружие ближнего боя]] + 2d10).
3. Бонусный урон имеет тот же тип и источник что и основной урон оружия. 
4. После получения урона, цель должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
5. ([[Танцы]]) - эффект - ([[Отвлечение]]) - ([[Физический]]) - ([[ФИЗ]]). 
6. В случае провала на цель накладывается состояние ([[(-) Сбитое внимание]]).
# (-) Сбитое внимание

1. Цель получает помехи на все броски навыка ([[Внимательность]]).
2. Она предоставляет превосходство для всех атак по себе.
# Избавление от эффекта

1. Эффект действует до конца сцены.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Танцы]]) - эффект - ([[Отвлечение]]) - ([[Физический]]) - ([[ФИЗ]]). 

Свойства способности:
1. Эффект: Мгновенный урон / Отвлечение.
2. Источник: Физический / Физический.
3. Тип: ФИЗ / ФИЗ.
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: Ближний бой вашего персонажа / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца сцены.
