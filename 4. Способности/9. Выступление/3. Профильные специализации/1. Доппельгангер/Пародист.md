(П) Пассивная способность
Требования: ТЕЛ / ЛОВ / ИНТ / ХАР / ОБА / ВОС / УДЧ: 2.
Подходящее выступление: Актерство.

1. Ваш персонаж может совершать броски (Актерства) вместо бросков (Манипуляции). 
2. Он может полноценно использовать все способности связанные с (Манипуляцией), при этом совершая броски (Актерства). 
3. Если он пытается притворяться кем-то другим, то получает превосходство на этот бросок.
