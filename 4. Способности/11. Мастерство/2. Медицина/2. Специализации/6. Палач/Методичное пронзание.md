(А) Малое действие (1р/Раунд) (Рассудок: 20).
Требования: ТЕЛ / ЛОВ / ИНТ / ХАР / ВОС: 3.

1. Ваш персонаж совершает встречную проверку с целью:
2. ([[1. Основные правила/3. Навыки/8. Мастерство/Медицина]]) вашего персонажа против спасброска цели ([[Мгновенный урон]]) - ([[Физический]]) - ([[ФИЗ]]). 
3. В случае, если результат вашего персонажа превышает результат цели, она получает 6d10 + характеристика навыка ([[1. Основные правила/3. Навыки/8. Мастерство/Медицина]]) пунктов урона по здоровью ([[Внутренний]] - [[Физический]] - [[ФИЗ]]).
4. После получения урона, цель должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
5. ([[1. Основные правила/3. Навыки/8. Мастерство/Медицина]]) - эффект - ([[Травма]]) - ([[Физический]]) - ([[ФИЗ]]). 
6. В случае провала на цель накладывается состояние ([[(-) Травма - пронзен]]).
7. Эта способность считается применением приема (Первая помощь) и на нее распространяются все усиления усиливающие этот прием. 
# (-) Травма - пронзен

1. Каждый раз, когда цель предпринимает какое-то действие тратя ([[Малое действие]]) или ([[Стандартное действие]]), она получает 6d10+40 пунктов урона по здоровью ([[Внутренний]] - [[Физический]] - [[ФИЗ]]). 
# Избавление от эффекта

1. Эффект действует до конца сцены. 
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[1. Основные правила/3. Навыки/8. Мастерство/Медицина]]) - эффект - ([[Травма]]) - ([[Физический]]) - ([[ФИЗ]]). 

Свойства способности:
1. Эффект: Мгновенный урон / Травма.
2. Источник: Физический / Физический.
3. Тип: ФИЗ / ФИЗ. 
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: Ближний бой вашего персонажа / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца сцены.
