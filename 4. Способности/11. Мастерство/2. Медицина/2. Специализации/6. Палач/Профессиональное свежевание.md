(А) Малое действие (1р/Раунд) (Рассудок: 20).
Требования: ТЕЛ / ЛОВ / ИНТ / ХАР / ВОС: 3.

1. Ваш персонаж совершает встречную проверку с целью:
2. (Медицина) вашего персонажа против спасброска цели (Нанесение урона) - (Физический) - (ФИЗ). 
3. В случае, если результат вашего персонажа превышает результат цели, она получает 6d10 + ТЕЛ / ЛОВ / ИНТ / ХАР / ВОС пунктов урона по здоровью (Внутренний - Физический - ФИЗ).
4. После получения урона, цель должна пройти спасбросок против пассивной сложности навыка:
5. Медицина - эффект - (Периодический урон) - (Физический) - (ФИЗ). 
6. В случае провала на цель накладывается состояние (Кровотечение).
7. Эта способность считается применением приема (Первая помощь) и на нее распространяются все усиления усиливающие этот прием. 
# Кровотечение (Н - Состояние)

1. Цель получает 10 пунктов периодического урона по здоровью в начале каждого своего хода (Внутренний - Физический - ФИЗ).
# Избавление от эффекта

1. Эффект действует до конца сцены. 
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка:
3. Медицина - эффект - (Периодический урон) - (Физический) - (ФИЗ). 

Свойства способности:
1. Эффект: Нанесение урона / Периодический урон.
2. Источник: Физический / Физический.
3. Тип: ФИЗ / ФИЗ. 
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: Ближний бой вашего персонажа / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца сцены.
