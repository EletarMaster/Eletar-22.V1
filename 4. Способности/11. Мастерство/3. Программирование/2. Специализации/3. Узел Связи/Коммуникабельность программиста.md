(П) Пассивная способность
Требования: ИНТ / ОБА / ВОС: 2.

1. Ваш персонаж может использовать (ОБА) для бросков (Программирования).
2. Ваш может использовать (ОБА), как характеристику для выполнения требований к изучению способностей в категориях (Программирование).
3. Ваш персонаж может использовать (ОБА), как характеристику для определения сложности спасброска против эффектов (Программирования).
4. Один раз за сцену, ваш персонаж может перебросить любую проверку (Программирования).
5. Он может использовать эту способность, даже если получил критический провал - чистую "1" на броске d20.
