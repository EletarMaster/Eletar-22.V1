(Р) Реакция (1р/Сцена) (Рассудок: 20)
Требования: ИНТ / ВОС: 2.
Условия срабатывания: ваш персонаж успешно проникает в какую-то информационную систему.

1. Сразу же после проникновения, ваш персонаж может пройти проверку программирования в качестве хакерства.
2. После этого, на вашего персонажа накладывается состояние (Цифровая незаметность).
# Цифровая незаметность (Нейтральное - Состояние)

1. Нахождение персонажа в системе становится невидимо для ее служб безопасности.
2. Любое агрессивное или вредоносное действие по отношению к системе позволяет службам безопасности совершить активный бросок обнаружения.
3. Любой провал проверки программирования внутри системы тут же рассеивает этот эффект.
4. В момент попадания под это состояние, цель может либо принять минимальную сложность обнаружения = 25, либо сама пройти проверку навыка, который используется ею для хакерства. По умолчанию - это программирование. Однако она не может получить результат хуже 25, даже если получит чистую критический провал - чистую "1" на броске d20. 


Свойства способности:
1. Эффект: Изменение.
2. Источник: Физический.
3. Тип: ФИЗ. 
4. Цель: Ваш персонаж.
5. Шаблон: Ваш персонаж.
6. Дистанция: Ваш персонаж.
7. Длительность: До конца сцены.
