(П) Пассивная способность
Требования: ИНТ / ХАР / ВОС: 2.

1. Ваш персонаж может использовать (ХАР) для бросков (Программирования).
2. Ваш может использовать (ХАР), как характеристику для выполнения требований к изучению способностей в категориях (Программирование).
3. Ваш персонаж может использовать (ХАР), как характеристику для определения сложности спасброска против эффектов (Программирования).
4. Один раз за сцену, ваш персонаж может перебросить проверку (Программирования).
5. Он может использовать эту способность, даже если получил критический провал - чистую "1" на броске d20.
