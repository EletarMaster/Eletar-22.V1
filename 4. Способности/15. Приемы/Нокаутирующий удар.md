(ПРИ) Стандартное действие (Ресурсы: 0)
Требования: Нет. 

1. Ваш персонаж атакует цель в ([[Ближнем бою]]).
2. В случае попадания, цель должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Ближний бой]]) - эффект - ([[Выведен из строя]]) - ([[Физический]]) - ([[ФИЗ]]). 
4. В случае провала, на цель накладывается состояние ([[(-) Без сознания]]).
5. Эта атака не наносит урон.
# (-) Без сознания

1. Цель теряет сознание и падает на землю. 
2. Цель не может предпринимать никаких действий или передвигаться.
3. Она предоставляет превосходство для всех атак по себе.
4. Она является полностью беззащитной. 
# Избавление от эффекта

1. Эффект действует 4 часа. 
2. В начале каждого часа, цель может попытаться пройти спасбросок против пассивной сложности навыка:
3. ([[Ближний бой]]) - эффект - ([[Выведен из строя]]) - ([[Физический]]) - ([[ФИЗ]]). 

Свойства способности:
1. Эффект: Выведен из строя.
2. Источник: Физический.
3. Тип: ФИЗ.
4. Цель: 1 Цель.
5. Шаблон: 1 Цель.
6. Дистанция: Ближний бой вашего персонажа.
7. Длительность: Мгновенно.
