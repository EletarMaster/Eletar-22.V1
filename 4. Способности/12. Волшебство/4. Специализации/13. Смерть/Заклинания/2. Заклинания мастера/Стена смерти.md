(З) Стандартное действие (1р/Сцена) (Энергия: 60).
Требования: Волшебство: +2; Волшебство: +3.

1. Ваш персонаж создаёт стену, сотканную из источника ([[Смерть]]), на дистанции 10 клеток.
2. Стена занимает 5 клеток в длину.
3. Высота стены — 2 клетки.
4. Запас ресурса ([[Здоровье]]) / Прочности стены = 200 пунктам.
5. Стена получает урон только от источника ([[Жизнь]]).
6. Стена может двигаться по желанию вашего персонажа.
7. Когда стена проходит по цели, если цель является нежитью, она восстанавливает 3d10 + 40 пунктов ресурса ([[Здоровье]]).
8. Если цель является живым существом, она должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
9. ([[Волшебство]]) - эффект - ([[Мгновенный урон]]) - ([[Смерть]]) - ([[МИСТ]]).
10. В случае провала, цель получает 3d10 + 40 пунктов урона по ресурсу ([[Здоровье]]) - ([[Внутренний]] - [[Смерть]] - [[МИСТ]]).
11. После получения урона, на цель накладывается состояние ([[(-) Запрет на восстановление]]).
12. Движение стены — это ([[Малое действие]]).
13. Одновременно может существовать только 1 такая стена.

# (-) Запрет на восстановление

1. Цель не может восстанавливать ресурсы никакими способами.

# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. Цель не получает никаких спасбросков против этого эффекта.

Свойства способности:
1. Эффект: Призыв / Мгновенное восстановление / Мгновенный урон / Запрет.
2. Источник: Смерть / Смерть / Смерть / Смерть.
3. Тип: МИСТ / МИСТ / МИСТ / МИСТ.
4. Цель: 5 клеток / Все цели в шаблоне / Все цели в шаблоне / Цель первоначального воздействия.
5. Шаблон: 5 клеток / Линия движения стены / Линия движения стены / Цель первоначального воздействия.
6. Дистанция: 10 клеток / Линия движения стены / Линия движения стены / Цель первоначального воздействия.
7. Длительность: До конца сцены / Мгновенно / Мгновенно / До конца следующего хода цели.
