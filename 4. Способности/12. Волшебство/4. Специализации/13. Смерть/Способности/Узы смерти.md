(Р) Реакция (1р/Раунд) (Энергия: 30).
Требования: Волшебство: +2; Волшебство: +3.
Условия срабатывания: живое существо в радиусе 5 клеток вокруг вашего персонажа получает урон.

1. Как только живое существо в радиусе 5 клеток вокруг вашего персонажа получает урон, ваш персонаж заставляет другое существо в этом радиусе пройти с собой встречную проверку навыка:
2. ([[Волшебство]]) вашего персонажа против спасброска целей ([[Мгновенный урон]]) - ([[Смерть]]) - ([[МИСТ]]). 
3. В случае провала, цель получет такое же количество урона по ресурсу ([[Здоровье]]) - ([[Внутренний]] - [[Смерть]] - [[МИСТ]]).
4. После получения урона, на цель накладывается состояние ([[(-) Запрет на восстановление]]).
5. Если цель являются нежитью, она восстанавливает такое же количество ресурсов.
# (-) Запрет на восстановление

1. Цель не может восстанавливать ресурсы никакими способами.  
# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. Цель не получает никаких спасбросков против этого эффекта. 

Свойства способности:
1. Эффект: Мгновенный урон / Запрет / Мгновенное восстановление.
2. Источник: Смерть / Смерть / Смерть.
3. Тип: МИСТ / МИСТ / МИСТ.
4. Цель: 1 Цель / Цель первоначального воздействия / 1 Цель.
5. Шаблон: 1 Цель / Цель первоначального воздействия / 1 Цель.
6. Дистанция: 5 клеток / Цель первоначального воздействия / 1 Цель.
7. Длительность: Мгновенно / До конца следующего хода цели / Мгновенно.
