(З) Стандартное действие (Энергия: 20).
Требования: Волшебство: +2.

1. Ваш персонаж атакует все цели в конусе длинною 3 клетки в ([[Дальнем бою зарядами мистики]]).
2. Если цели являются живыми существами, они восстанавливают 12d8 + характеристика навыка ([[Волшебство]]) пунктов ресурса ([[Здоровье]]).
3. Если цели являются нежитью, они получают 12d8 + характеристика навыка ([[Волшебство]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внешний]] - [[Жизнь]] - [[МИСТ]]).
4. После получения урона, на цели накладывается состояние ([[(-) Запрет на восстановление]]).

# (-) Запрет на восстановление

1. Цель не может восстанавливать ресурсы никакими способами.

# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. Цель не получает никаких спасбросков против этого эффекта.

Свойства способности:
1. Эффект: Мгновенное восстановление / Мгновенный урон / Запрет.
2. Источник: Жизнь / Жизнь / Жизнь.
3. Тип: МИСТ / МИСТ / МИСТ.
4. Цель: Все цели в шаблоне / Все цели в шаблоне / Все цели в шаблоне.
5. Шаблон: Конус длинною 3 клетки / Конус длинною 3 клетки / Конус длинною 3 клетки.
6. Дистанция: 3 клетки / 3 клетки / 3 клетки.
7. Длительность: Мгновенно / Мгновенно / До конца следующего хода цели.
