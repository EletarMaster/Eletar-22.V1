# Перемещение цели с помощью телекинеза

1. Ваш персонаж совершает встречную проверку с целью:
2. ([[Волшебство]]) - эффект - ([[Вынужденное движение]]) - ([[Сила]]) - ([[МЕНТ]]).
3. В случае, если результат вашего персонажа превышает результат цели, он может передвинуть цель на 10 клеток используя ([[Полет]]).
4. Союзники могут добровольно провалить спасбросок.
5. Это передвижение не провоцирует срабатывание атак - реакций. 
6. Если цель сталкивается с преградой, она получает урон по здоровью от оружия ближнего боя ([[Удар о преграду]]).
7. Параметры урона меняются на ([[Внутренний]] - [[Физический]] - [[ФИЗ]]).
8. Максимальная грузоподъемность этой способности = 300 кг.
# Сдавливание цели с помощью телекинеза

1. Ваш персонаж совершает встречную проверку с целью:
2. ([[Волшебство]]) - эффект - ([[Мгновенный урон]]) - ([[Сила]]) - ([[МЕНТ]]).
 3. В случае, если результат вашего персонажа превышает результат цели, она получает 8d10 + характеристика навыка ([[Волшебство]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внутренний]] - [[Сила]] - [[МИСТ]]).

1. Эффект: Вынужденное движение / Мгновенный урон.
