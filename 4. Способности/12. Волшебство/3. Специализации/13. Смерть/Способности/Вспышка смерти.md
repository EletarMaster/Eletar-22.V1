(А) Стандартное действие (Рассудок: 30).
Требования: Волшебство: +2.

1. Ваш персонаж совершает встречную проверку с всеми целями являющимися живыми существами в области радиусом 1 клетка на дистанции 10 клеток:
2. ([[Волшебство]]) вашего персонажа против спасброска целей ([[Мгновенный урон]]) - ([[Смерть]]) - ([[МИСТ]]). 
3. В случае провала, цели получают 5d10 + характеристика навыка ([[Волшебство]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внутренний]] - [[Смерть]] - [[МИСТ]]).
4. После получения урона, на цель накладывается состояние ([[(-) Запрет на восстановление]]).
5. Если цели являются нежитью, ваш персонаж восстанавливает им 5d10 + характеристика навыка ([[Волшебство]]) пунктов ресурса ([[Здоровье]]).
# (-) Запрет на восстановление

1. Цель не может восстанавливать ресурсы никакими способами.  
# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. Цель не получает никаких спасбросков против этого эффекта. 

Свойства способности:
1. Эффект: Мгновенный урон / Запрет / Мгновенное восстановление.
2. Источник: Смерть / Смерть / Смерть.
3. Тип: МИСТ / МИСТ / МИСТ.
4. Цель: Все цели в шаблоне / Цель первоначального воздействия / Цель первоначального воздействия.
5. Шаблон: 1 клетка вокруг выбранной клетки / Цель первоначального воздействия / Цель первоначального воздействия.
6. Дистанция: 10 клеток / Цель первоначального воздействия / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца следующего хода цели / Мгновенно.
