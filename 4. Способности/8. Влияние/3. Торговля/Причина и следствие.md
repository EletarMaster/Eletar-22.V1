(А) Малое действие (1р/Раунд) (Рассудок: 20).
Требования: ИНТ / ХАР / ОБА / ВОС: 4.

1. Ваш персонаж совершает встречную проверку с целью:
2. ([[Торговля]]) вашего персонажа против спасброска цели ([[Контроль разума]]) - ([[Психика]]) - ([[МЕНТ]]). 
3. В случае, если результат вашего персонажа превышает результат цели, ваш персонаж узнает сразу две вещи о своем собеседнике:
4. Первая - какая у него есть на данный момент самая актуальная проблема.
5. Вторая - как улучшится его жизнь, если эта проблема решится и что получит тот кто для него эту проблему решит.
6. Не считается агрессивным действием. 

Свойства способности:
1. Эффект: Контроль разума.
2. Источник: Психика.
3. Тип: МЕНТ. 
4. Цель: 1 Цель.
5. Шаблон: 1 Цель.
6. Дистанция: Дальность ведения диалога (Базово = 20 клеткам).
7. Длительность: Мгновенно.
