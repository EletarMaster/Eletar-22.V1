(П) Пассивная способность.
Требования: ИНТ / ХАР / ОБА: 3.

1. Один раз за сцену, когда ваш персонаж совершает бросок инициативы для определения порядка хода, он также совершает бросок лидерства.
2. Результат проверки лидерства считается дополнительным результатом броска инициативы. 
3. Ваш персонаж может передать этот результат кому-то из своих союзников, участвующих в том же броске инициативы что и он.
4. Таким образом - этот союзник получает полноценный дополнительный ход в указанную инициативу. 
5. Ваш персонаж не может передать этот дополнительный ход себе. 
6. Даже если персонажей обладающих этой способностью несколько, в рамках одной сцены применить ее может только один из них.
