# (+) Твердыня Трауда (1)

1. Цель защищена абсолютным каменным панцирем.
2. Запас здоровья барьера = 3000 пунктам.
3. Барьер получает ВЕСЬ урон вместо цели.
4. Пока барьер не разрушен, цель игнорирует все негативные воздействия с типами ([[ФИЗ]]); ([[МЕНТ]]); ([[МИСТ]]).
5. Цель может действовать как обычно.
