(К) Стандартное действие (1р/Раунд) (Энергия: 10).
Требования: Единение: +2.

1. Ваш персонаж атакует цель в ([[Дальнем бою зарядами мистики]]).
2. В случае попадания, цель получает 3d10 + характеристика навыка ([[Единение]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внешний]] - [[Ветер]] - [[МИСТ]]).
3. Цель должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
4. ([[Единение]]) - эффект - ([[Запрет]]) - ([[Ветер]]) - ([[МИСТ]]).
5. В случае провала, на цель накладывается состояние ([[(-) Связан]]).

# (-) Связан

1. Цель не может передвигаться.
2. Цель не может использовать способности, позволяющие ей передвигаться.
3. Цель получает помеху на все проверки ([[ТЕЛ]]) и ([[ЛОВ]]).
4. Цель получает штраф -4 на все проверки ([[ТЕЛ]]) и ([[ЛОВ]]).
5. Она предоставляет превосходство для всех атак по себе.

# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Запрет]]) - ([[Ветер]]) - ([[МИСТ]]).

# Дополнительная трата ресурсов

1. (Энергия: 10): Урон: 3d10.
2. (Энергия: 30): Урон: 6d10.
3. (Энергия: 50): Урон: 10d10.
4. (Энергия: 80): Урон: 15d10.

Свойства способности:
1. Эффект: Мгновенный урон / Запрет.
2. Источник: Ветер / Ветер.
3. Тип: МИСТ / МИСТ.
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: 10 клеток / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца следующего хода цели.
