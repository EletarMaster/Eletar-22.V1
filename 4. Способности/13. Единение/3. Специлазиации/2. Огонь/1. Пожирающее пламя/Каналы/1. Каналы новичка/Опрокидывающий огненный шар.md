(К) Стандартное действие (1р/Раунд) (Энергия: 10).
Требования: Единение: +2.

1. Ваш персонаж атакует цель на дистанции 10 клеток в ([[Дальнем бою зарядами мистики]]).
2. В случае попадания, цель получает 3d12 + характеристика навыка ([[Единение]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внешний]] - [[Огонь]] - [[МИСТ]]).
3. После получения урона, цель должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
4. ([[Единение]]) - эффект - ([[Вынужденное движение]]) - ([[Огонь]]) - ([[МИСТ]]).
5. В случае провала, на цель накладывается состояние ([[(-) Сбит с ног]]).

# Дополнительная трата ресурсов

1. (Энергия: 10): Базовый эффект. Урон: 3d12.
2. (Энергия: 30): Урон: 6d12.
3. (Энергия: 50): Урон: 10d12.
4. (Энергия: 80): Урон: 15d12.

# (-) Сбит с ног

1. Цель сбита с ног.
2. Она предоставляет превосходство для всех атак ближнего боя по себе.
3. Все атаки дальнего боя по цели от противников дальше 5 клеток получают помеху.
4. Цель получает помеху на все атаки и агрессивные действия.
5. Она может передвигаться ползком со скоростью 2 клетки.

# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Вынужденное движение]]) - ([[Огонь]]) - ([[МИСТ]]).

Свойства способности:
1. Эффект: Мгновенный урон / Вынужденное движение.
2. Источник: Огонь / Огонь.
3. Тип: МИСТ / МИСТ.
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: 10 клеток / 10 клеток.
7. Длительность: Мгновенно / До конца следующего хода цели.
