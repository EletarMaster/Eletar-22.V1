(К) Малое действие (1р/Раунд) (Энергия: 30).
Требования: Единение: +2.

1. Ваш персонаж совершает встречную проверку с целью:
2. ([[Единение]]) вашего персонажа против спасброска цели ([[Запрет]]) - ([[Вода]]) - ([[МИСТ]]).
3. В случае, если результат вашего персонажа превышает результат цели, на нее накладывается состояние ([[(-) Связан]]).
4. Вне зависимости от результата спасброска, на цель автоматически накладывается состояние ([[(=) Влага]]).

# (-) Связан

1. Цель не может передвигаться.
2. Цель не может использовать способности, позволяющие ей передвигаться.
3. Цель получает помеху на все проверки ([[ТЕЛ]]) и ([[ЛОВ]]).
4. Цель получает штраф -4 на все проверки ([[ТЕЛ]]) и ([[ЛОВ]]).
5. Она предоставляет превосходство для всех атак по себе.

# (=) Влага

1. Получаемый урон от источника ([[Вода]]) снижается на: 50.
2. Получаемый урон от источника ([[Огонь]]) снижается на: 50.
3. Получаемый урон от источника ([[Электричество]]) увеличивается на: 50.
4. Получаемый урон от источника ([[Холод]]) увеличивается на: 50.
5. Цель получает превосходство на спасброски против эффектов с источником ([[Вода]]).
6. Цель получает превосходство на спасброски против эффектов с источником ([[Огонь]]).
7. Цель получает помеху на все спасброски против эффектов с источником ([[Электричество]]).
8. Цель получает помеху на все спасброски против эффектов с источником ([[Холод]]).
9. Если цель соприкоснется с большим количеством огня или тепла эффект тут же рассеется.

# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Запрет]]) - ([[Вода]]) - ([[МИСТ]]).

# Дополнительная трата ресурсов

1. (Энергия: 30): 1 Цель.
2. (Энергия: 60): 2 Цели.
3. (Энергия: 90): 3 Цели.
4. (Энергия: 120): 4 Цели.

Свойства способности:
1. Эффект: Запрет / Изменение.
2. Источник: Вода / Вода.
3. Тип: МИСТ / МИСТ.
4. Цель: 1-4 Цели / Цель первоначального воздействия.
5. Шаблон: 1-4 Цели / Цель первоначального воздействия.
6. Дистанция: 10 клеток / Цель первоначального воздействия.
7. Длительность: До конца следующего хода цели / До конца сцены.
