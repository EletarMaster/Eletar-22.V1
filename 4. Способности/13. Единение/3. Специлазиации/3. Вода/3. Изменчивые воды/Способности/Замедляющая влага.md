(Р) Реакция (1р/Раунд) (Энергия: 20).
Требования: Единение: +2.
Условия срабатывания: ваш персонаж успешно наложил на цель состояние Влага с типом МИСТ.

1. Цель, на которую было наложено состояние ([[(=) Влага]]), должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
2. ([[Единение]]) - эффект - ([[Ослабление]]) - ([[Вода]]) - ([[МИСТ]]).
3. В случае провала, на нее накладывается состояние ([[(-) Замедление]]).
4. Если целей было несколько, каждая из них должна пройти этот спасбросок.

# (-) Замедление

1. Скорость цели снижается на 8 клеток.
2. Если скорость опускается до 0, цель не может передвигаться.
3. Цель не может использовать способности, позволяющие ей передвигаться.

# Избавление от эффекта

1. Эффект действует до конца сцены.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Ослабление]]) - ([[Вода]]) - ([[МИСТ]]).

Свойства способности:
1. Эффект: Ослабление.
2. Источник: Вода.
3. Тип: МИСТ.
4. Цель: Все цели, на которые было наложено Влага.
5. Шаблон: Все цели, на которые было наложено Влага.
6. Дистанция: Цель первоначального воздействия.
7. Длительность: До конца сцены.
