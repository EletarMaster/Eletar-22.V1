(К) Стандартное действие (1р/Раунд) (Энергия: 10).
Требования: Единение: +2.

1. Ваш персонаж атакует цель в ([[Дальнем бою зарядами мистики]]).
2. В случае попадания, цель получает 5d10 + характеристика навыка ([[Единение]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внешний]] - [[Вода]] - [[МИСТ]]).
3. После получения урона, на цель автоматически накладывается состояние ([[(=) Влага]]).
4. В случае критического попадания, цель должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
5. ([[Единение]]) - эффект - ([[Ослабление]]) - ([[Вода]]) - ([[МИСТ]]).
6. В случае провала, на цель дополнительно накладывается состояние ([[(-) Замедление]]).

# Дополнительная трата ресурсов

1. (Энергия: 10): Базовый эффект. Урон: 5d10.
2. (Энергия: 30): Урон: 10d10.
3. (Энергия: 50): Урон: 15d10.
4. (Энергия: 80): Урон: 20d10.

# (=) Влага

1. Получаемый урон от источника ([[Вода]]) снижается на: 50.
2. Получаемый урон от источника ([[Огонь]]) снижается на: 50.
3. Получаемый урон от источника ([[Электричество]]) увеличивается на: 50.
4. Получаемый урон от источника ([[Холод]]) увеличивается на: 50.
5. Цель получает превосходство на спасброски против эффектов с источником ([[Вода]]).
6. Цель получает превосходство на спасброски против эффектов с источником ([[Огонь]]).
7. Цель получает помеху на все спасброски против эффектов с источником ([[Электричество]]).
8. Цель получает помеху на все спасброски против эффектов с источником ([[Холод]]).
9. Если цель соприкоснется с большим количеством огня или тепла эффект тут же рассеется.

# (-) Замедление

1. Скорость цели снижается на 8 клеток.
2. Если скорость опускается до 0, цель не может передвигаться.
3. Цель не может использовать способности, позволяющие ей передвигаться.

# Избавление от эффекта

1. Эффект действует до конца сцены.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Ослабление]]) - ([[Вода]]) - ([[МИСТ]]).

Свойства способности:
1. Эффект: Мгновенный урон / Изменение / Ослабление.
2. Источник: Вода / Вода / Вода.
3. Тип: МИСТ / МИСТ / МИСТ.
4. Цель: 1 Цель / Цель первоначального воздействия / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия / Цель первоначального воздействия.
6. Дистанция: 10 клеток / Цель первоначального воздействия / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца сцены / До конца сцены.
