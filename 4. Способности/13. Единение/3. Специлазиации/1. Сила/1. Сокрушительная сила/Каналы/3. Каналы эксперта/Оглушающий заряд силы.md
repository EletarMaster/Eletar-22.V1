(К) Стандартное действие (1р/Раунд) (Энергия: 50).
Требования: Единение: +2; Единение: +3; Единение: +5.

1. Ваш персонаж атакует цель в ([[Дальнем бою зарядами мистики]]).
2. В случае попадания, цель получает 5d8 + характеристика навыка ([[Единение]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внешний]] - [[Сила]] - [[МИСТ]]).
3. После получения урона, цель должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
4. ([[Единение]]) - эффект - ([[Блокировка]]) - ([[Сила]]) - ([[МИСТ]]).
5. В случае провала, на цель накладывается состояние ([[(-) Оглушение]]).

# Дополнительная трата ресурсов

1. (Энергия: 50): Базовый эффект. Урон: 5d8.
2. (Энергия: 80): Урон: 10d8.
3. (Энергия: 120): Урон: 15d8.
4. (Энергия: 150): Урон: 20d8.

# (-) Оглушение

1. Цель не может предпринимать никаких действий или передвигаться.
2. Она предоставляет превосходство для всех атак по себе.

# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Блокировка]]) - ([[Сила]]) - ([[МИСТ]]).

Свойства способности:
1. Эффект: Мгновенный урон / Блокировка.
2. Источник: Сила / Сила.
3. Тип: МИСТ / МИСТ.
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: 10 клеток / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца следующего хода цели.
