(К) Стандартное действие (1р/Раунд) (Энергия: 10).
Требования: Единение: +2.

1. Ваш персонаж атакует цель в ([[Дальнем бою зарядами мистики]]).
2. В случае попадания, цель получает 3d8 + характеристика навыка ([[Единение]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внешний]] - [[Сила]] - [[МИСТ]]).
3. После получения урона, цель должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
4. ([[Единение]]) - эффект - ([[Ослабление]]) - ([[Сила]]) - ([[МИСТ]]).
5. В случае провала, на цель накладывается состояние ([[(-) Замедление]]).

# Дополнительная трата ресурсов

1. (Энергия: 10): Урон: 3d8. Замедление.
2. (Энергия: 30): Урон: 6d8. Замедление.
3. (Энергия: 50): Урон: 10d8. Замедление.
4. (Энергия: 80): Урон: 15d8. Замедление.

# (-) Замедление

1. Скорость цели снижается на 8 клеток.
2. Если скорость опускается до 0, цель не может передвигаться.
3. Цель не может использовать способности позволяющие ей передвигаться.

# Избавление от эффекта

1. Эффект действует до конца сцены.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Ослабление]]) - ([[Сила]]) - ([[МИСТ]]).

Свойства способности:
1. Эффект: Мгновенный урон / Ослабление.
2. Источник: Сила / Сила.
3. Тип: МИСТ / МИСТ.
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: 10 клеток / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца сцены.
