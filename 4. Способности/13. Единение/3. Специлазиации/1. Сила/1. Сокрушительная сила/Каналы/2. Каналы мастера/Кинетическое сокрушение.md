(К) Стандартное действие (1р/Раунд) (Энергия: 30).
Требования: Единение: +2; Единение: +3.

1. Ваш персонаж атакует всех противников в области вокруг себя в радиусе 3 клеток в ([[Дальнем бою зарядами мистики]]).
2. В случае попадания, цели получают 3d8 + характеристика навыка ([[Единение]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внешний]] - [[Сила]] - [[МИСТ]]).
3. После получения урона, цели должны пройти спасбросок против пассивной сложности навыка вашего персонажа:
4. ([[Единение]]) - эффект - ([[Вынужденное движение]]) - ([[Сила]]) - ([[МИСТ]]).
5. В случае провала, на цель накладывается состояние ([[(-) Сбит с ног]]).
6. Эта атака является массовой.
7. Эту атаку нельзя контратаковать.

# Дополнительная трата ресурсов

1. (Энергия: 30): Базовый эффект. Урон: 3d8. Радиус: 3 клетки.
2. (Энергия: 50): Урон: 5d8. Радиус: 5 клеток.
3. (Энергия: 80): Урон: 10d8. Радиус: 8 клеток.
4. (Энергия: 120): Урон: 12d8. Радиус: 12 клеток.

# (-) Сбит с ног

1. Цель сбита с ног.
2. Она предоставляет превосходство для всех атак ближнего боя по себе.
3. Все атаки дальнего боя по цели от противников дальше 5 клеток получают помеху.
4. Цель получает помеху на все атаки и агрессивные действия.
5. Она может передвигаться ползком со скоростью 2 клетки.

# Избавление от эффекта

1. Эффект действует до конца следующего хода цели.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Вынужденное движение]]) - ([[Сила]]) - ([[МИСТ]]).

Свойства способности:
1. Эффект: Мгновенный урон / Вынужденное движение.
2. Источник: Сила / Сила.
3. Тип: МИСТ / МИСТ.
4. Цель: Все противники в шаблоне / Все противники в шаблоне.
5. Шаблон: Область радиусом 3-12 клеток вокруг вашего персонажа / Область радиусом 3-12 клеток вокруг вашего персонажа.
6. Дистанция: Ваш персонаж / Ваш персонаж.
7. Длительность: Мгновенно / До конца следующего хода цели.
