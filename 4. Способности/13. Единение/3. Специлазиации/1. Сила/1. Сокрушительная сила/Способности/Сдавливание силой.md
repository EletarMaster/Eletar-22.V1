(А) Малое действие (1р/Раунд) (Энергия: 30).
Требования: Единение: +2; Единение: +3; Единение: +5.

1. Ваш персонаж совершает встречную проверку с целью:
2. ([[Единение]]) вашего персонажа против спасброска цели ([[Мгновенный урон]]) - ([[Сила]]) - ([[МИСТ]]).
3. В случае, если результат вашего персонажа превышает результат цели, она получает 6d8 + характеристика навыка ([[Единение]]) пунктов урона по ресурсу ([[Здоровье]]) - ([[Внутренний]] - [[Сила]] - [[МИСТ]]).
4. Этот урон — это ([[Тяжелый урон]]).
5. Если цель получила урон от этой способности, она должна пройти спасбросок против пассивной сложности навыка вашего персонажа:
6. ([[Единение]]) - эффект - ([[Травма]]) - ([[Сила]]) - ([[МИСТ]]).
7. В случае провала, на нее накладывается состояние ([[(-) Тяжелая травма]]).

# Дополнительная трата ресурсов

1. (Энергия: 30): Базовый эффект. Урон 6d8.
2. (Энергия: 50): Урон 10d8.
3. (Энергия: 80): Урон 15d8.
4. (Энергия: 120): Урон 22d8.

# (-) Тяжелая травма

1. Цель получает помеху на все проверки ([[ТЕЛ]]) и ([[ЛОВ]]).
2. Каждый раз, когда цель предпринимает какое-то действие тратя ([[Малое действие]]) или ([[Стандартное действие]]), она получает 4d10+20 пунктов урона по здоровью ([[Внутренний]] - [[Физический]] - [[ФИЗ]]).

# Избавление от эффекта

1. Эффект действует до конца сцены.
2. В начале каждого своего хода, цель может попытаться пройти спасбросок против пассивной сложности навыка вашего персонажа:
3. ([[Единение]]) - эффект - ([[Травма]]) - ([[Сила]]) - ([[МИСТ]]).

Свойства способности:
1. Эффект: Мгновенный урон / Травма.
2. Источник: Сила / Сила.
3. Тип: МИСТ / МИСТ.
4. Цель: 1 Цель / Цель первоначального воздействия.
5. Шаблон: 1 Цель / Цель первоначального воздействия.
6. Дистанция: 10 клеток / Цель первоначального воздействия.
7. Длительность: Мгновенно / До конца сцены.
