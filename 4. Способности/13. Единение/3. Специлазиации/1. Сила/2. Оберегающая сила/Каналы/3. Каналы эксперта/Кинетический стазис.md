# (=) Кинетический стазис (1)

1. Цель застывает в кинетическом коконе.
2. Цель не может предпринимать никаких действий или передвигаться.
3. Она предоставляет превосходство для всех атак по себе.
4. Получаемый урон (ВЕСЬ) снижается на: 100.
5. На цель не может действовать больше одного состояния "Стазис".
