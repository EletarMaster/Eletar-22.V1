(П) Пассивная способность
Требования: Развитие обаяния (Мастер)

1. Персонаж может выбрать обаяние в качестве характеристики для бросков внимательности.
2. Персонаж может выбрать обаяние в качестве характеристики для использования защиты (Пассивная внимательность).
3. Персонаж может выбрать обаяние в качестве характеристики для бросков плутовства.
