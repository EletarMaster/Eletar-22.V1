Ветка позволяющая многогранно усилить персонажа, заимствовать сильные стороны других веток. Улучшает бдительность персонажа и позволяет действовать на пределе своих возможностей. 

Итоговое усиление параметров персонажа после прокачки:
# Спасброски

1. Персонаж может использовать (ВОС) в качестве характеристики для спасбросков против эффектов с типом (ФИЗ).
2. Персонаж может использовать (ВОС) в качестве характеристики для спасбросков против эффектов с типом (МЕНТ).
3. Персонаж может использовать (ВОС) в качестве характеристики для спасбросков против эффектов с типом (МИСТ).
4. Спасбросок против эффектов с типом (ФИЗ): +2.
5. Спасбросок против эффектов с типом (МЕНТ): +2.
6. Спасбросок против эффектов с типом (МИСТ): +2.
# Навыки

1. Персонаж может полноценно использовать (ВОС) как характеристику для (Акробатики).
2. Персонаж может полноценно использовать (ВОС) как характеристику для (Плутовства).
# Защиты

1. Защита (Уклонение): +4.
2. Защита (Пассивная внимательность): +4.
3. Персонаж может использовать (ВОС) в качестве характеристики для использования защиты (Уклонение).
# Минимальный результат проверки

1. Минимальный результат броска d20 при проверках восприятия персонажа = 10.
