(П) Пассивная способность
Требования: Развитие удачи (Мастер)

1. Персонаж может полноценно использовать (УДЧ) как характеристику для (Акробатики).
2. Персонаж может использовать (УДЧ) в качестве характеристики для использования защиты (Уклонение).
3. Персонаж может полноценно использовать (УДЧ) как характеристику для (Плутовства).
