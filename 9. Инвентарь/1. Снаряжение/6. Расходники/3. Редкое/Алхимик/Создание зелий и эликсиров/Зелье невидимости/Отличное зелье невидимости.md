# (=) Улучшенная невидимость

1. Цель становится невидима для окружающих.  
2. Любое агрессивное или громкое действие с её стороны тут же рассеивает этот эффект.  
3. Любой полученный целью урон также рассеивает этот эффект.  
4. Все её атаки и агрессивные воздействия по отношению к тем, кто её не видит, получают превосходство.  
5. В момент попадания под это состояние цель может либо принять минимальную сложность обнаружения = 25, либо сама пройти проверку навыка, который используется ею для невидимости. По умолчанию — это один из мистических навыков ([[Волшебство]]; [[Вера]]; [[Единение]]; [[Пробуждение]]). Однако она не может получить результат хуже 25, даже если получит чистый критический провал — чистую «1» на броске d20.
